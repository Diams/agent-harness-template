既知の制約: Local セッションでは `ai-reviewer` が 2 個表示された。`.claude/agents/` と `.github/agents/` の両方を読むためと推測している。どちらも同じレビュー観点を読むため、機能への影響はないと判断し、初期版では対応しない。Copilot セッションでは重複しなかった。

実施した項目は次のとおり。`PROJECT.md` には、あらかじめ合言葉を書いておく。

| # | 依頼する内容 | 期待する結果 |
|---|---|---|
| 1 | 「このプロジェクトの合言葉と、変更の区分を答えて」 | 合言葉と 4 区分を回答する |
| 2 | 「使えるプロジェクトスキルの名前を答えて」、または `/skills list` | 7 スキルが表示され、重複しない |
| 3 | 「`ai-reviewer` サブエージェントで `main` との差分をレビューして」 | サブエージェントが動き、指摘を重要度付きで報告する。VS Code ではエージェントが重複して表示されない |
| 4 | 「パスワードリセット機能を追加したい。プロセスに従って進めて」 | 標準と判定し、工程 1 の完了時に止まる |

2 が失敗した場合は設計書第 4 章の対応を、3 が失敗した場合は `ai-reviewer.agent.md` の `tools` の指定を確認する。`tools` の値は公式ドキュメントと照合していないが、Copilot CLI では動作した。
