# スキルの追加手順

1. `.claude/skills/<name>/SKILL.md` を作成する。
2. 次の形式で書く。

   ```markdown
   ---
   name: <ディレクトリ名と同じ>
   description: <何をするか、いつ使うか>
   ---

   ## 入力
   ## 手順
   ## 成果物
   ## 完了条件
   ## 次の工程
   ```

3. 使用する各ツールでスキルを呼び出して確認する。

## 規則

- `name` と `description` は必須とする。
- `name` は英小文字、数字、ハイフンのみとし、ディレクトリ名と一致させる。一致しないと、読み込まれない環境がある。
- ツール固有の項目を使う場合は、無視されても動作する内容にする。

## テンプレート本体にスキルを追加するとき

`docs/harness/managed-paths.txt` にも `.claude/skills/<name>` を追加する。利用先で追加するスキルには不要で、更新時に上書きされない。
