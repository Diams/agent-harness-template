---
name: ai-review
description: PR を独立したサブエージェントでレビューし、結果を PR に記録する。PR の作成後に使う。
---

## 入力

PR の番号。

## 手順

1. `ai-reviewer` サブエージェントに PR の番号だけを渡してレビューを依頼する。実装時の経緯や判断は伝えない。
2. サブエージェントを実行できない環境では、自分でレビューせず、その旨を利用者に報告して止まる。
3. レビュー結果を PR のコメントとして投稿する。

## 成果物

PR 上のレビュー結果。

## 完了条件

レビュー結果が PR に記録され、「必須」の指摘が残っていない。

## 次の工程

「必須」の指摘があれば `implement` に戻り、修正後に再度レビューする。なければ人間にレビューを依頼して止まる。PR はマージしない。
