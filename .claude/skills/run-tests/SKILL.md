description: 受け入れ条件に照らしてテストを追加、実行し、結果を報告する。実装の後に使う。
---

## 入力

受け入れ条件(要件定義書または PR の説明欄)と、`PROJECT.md` のコマンド。

## 手順

1. 受け入れ条件ごとに、検証するテストがあるか確認する。
2. 足りないテストを追加する。
3. テストとリントを実行する。`PROJECT.md` にコマンドがなければ、利用者に確認する。
4. テストを通すためにテストや要件を弱めない。
5. 結果を報告する。実行できなかった項目はその理由を書く。

## 成果物

テストと実行結果。

## 完了条件

全テストが成功し、全受け入れ条件を確認した。

## 次の工程

失敗があれば `implement` に戻る。成功したら `commit-and-pr` に進む。
